# 跳跃与舞蹈：开源训练实跑

日期：2026-10-29；上游 [Jumper](https://github.com/KingKongRobotics/jumper) 提交 `b2e58669848a3ba4f209597cd6bebdfe9d0533a4`。Ubuntu 工作站 RTX PRO 6000 Blackwell，训练环境 `/data/Data14TB/envs/jumper-everyembodied`，PyTorch 2.8.0+cu128，MuJoCo 3.11.0。训练使用上游原有任务与参考数据；未修改训练算法。

## 跳跃

上游任务 `jumper.jump` 使用仓库内 `tasks/jumper/jump/ref/high_jump_flat.npz`，策略学习参考关节轨迹上的残差。以 `warp:cuda`、4096 环境计划训练 1000 次，工作站 GPU 有其他任务时，在保存第 300 次 checkpoint 后主动中止；训练日志中留有中断记录。上游默认 10000 次，不把这次视为收敛。

[跳跃 Notebook](../03-Notebook/06_跳跃_参考动作训练与评估.ipynb) 包含完整命令、可播放视频和 [结果 JSON](jump-result.json)。[训练日志](jump-training.txt) · [评估日志](jump-eval.txt) · [回放日志](jump-replay.txt) · [关节测量](jump-measure.csv) · [checkpoint](../02-可运行代码/checkpoints/jump-model-300.pt)。

上游 `tools/checks/jump_eval.py` 单环境、3 个 done 波次，观测噪声关闭，报告基座相对参考站立高度升高 0.158–0.160 m、累计全足离地 0.320–0.325 s。其离地阈值为每只足端接触力范数不大于 1 N；脚本在自动重置后采样，逐波统计，不应当作多种子成功率。视频是另一次 CPU 回放，400 Hz 物理、200 Hz 控制、观测噪声开启，运行 700 步约 3.5 秒；评估脚本测量值不是该视频的同步测量。

## 舞蹈

上游任务 `jumper.dance` 使用仓库内 `tasks/jumper/dance/media/demo.npz` 参考编舞。训练不需要音乐；仓库未提供配乐，本次仿真视频无声。与其他 GPU 进程共享工作站，使用 `warp:cuda`、1024 环境；此批量与上游示例的 4096 不同。第 200 次 checkpoint 的一次 200 Hz 物理、50 Hz 控制、观测噪声开启回放连续运行 1000 步、约 20 秒，视频可见抬爪和摆动。这只是约 235.7 秒参考编舞的开头片段。

[舞蹈 Notebook](../03-Notebook/07_舞蹈_参考动作训练与评估.ipynb) 记录训练过程、评估及内嵌视频；[结果 JSON](dance-result.json) · [回放日志](dance-replay.txt) · [关节测量](dance-measure.csv) · [视频所用 checkpoint](../02-可运行代码/checkpoints/dance-model-200.pt)。上游第 200 次训练日志的关节位置误差为 1.7688 rad（关节向量 L2），平均刚体位置误差 0.0642 m；这是训练批量指标，不是上述回放的误差。

训练实际完成 500 次、12,288,000 环境步，日志记录 10 分 34 秒。[最终 checkpoint](../02-可运行代码/checkpoints/dance-model-499.pt)（SHA-256 `5791a7797c4519e60b3e5b92a780c80611559b66e4f8b59c72502f984a83f0a7`）的独立回放同样运行满 1000 步、20 秒而未提前终止，画面可见抬爪和摆动。训练日志第 499 次的关节位置误差 L2 为 0.3505 rad、平均刚体位置误差为 0.0123 m。可查看[最终视频](../assets/dance-final.mp4)、[最终结果](dance-final-result.json)、[回放参数](dance-final-info.json)、[回放日志](dance-final-replay.txt)、[关节测量](dance-final-measure.csv)和[训练日志](dance-training.txt)。
