## 推荐路线

硬件应用路线按“地瓜机器人桌宠 → OpenClaw 家庭物资助手”学习，先完成设备接入，再组合语音、视觉、抓取和消息通知。机器人学习路线先完成策略抓取与仿真基础，再进入 AMD ROCm［AMD 开放式计算平台］专题，逐步完成数据、训练、评估和结果归档。达摩院专题提供全局技术视角，适合作为组队学习的导入材料。

专题之间共享概念，但不共享大型运行环境。每进入一个新专题，先按照该专题的环境章节创建独立环境，并把模型权重、数据集、缓存和批量视频放在实验目录中。教材仓库只保留正文、轻量脚本、配置、指标摘要和必要媒体，便于电子书构建与版本管理。

## 统一验收方法

完成专题时，至少保留下列四类产出：

1. 环境与设备信息，包括关键软件版本和计算设备；
2. 可重复执行的入口命令，以及输入、输出目录；
3. 一份可阅读的结果摘要，例如评估表、训练曲线或任务日志；
4. 一个能够说明系统行为的视频、截图或交互页面。

如果实验只完成环境导入或短步运行，应在结果标题中写明检查范围；正式结果则同时给出任务、回合数、成功判定和模型来源。
