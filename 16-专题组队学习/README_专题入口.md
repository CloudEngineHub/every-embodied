## 推荐顺序

硬件应用路线先学习地瓜机器人桌宠，再进入 OpenClaw 家庭物资助手；机器人学习路线先完成策略抓取与仿真基础，再进入 AMD ROCm 专题。达摩院专题提供全局技术视角，可以作为组队学习的导入材料。

模型权重、数据集、缓存和镜像文件放在独立实验目录中。专题目录只保留正文、轻量脚本、配置、指标摘要和必要媒体，便于电子书构建与版本管理。新目录或电子书导航应链接 [`README.md`](./README.md)。
