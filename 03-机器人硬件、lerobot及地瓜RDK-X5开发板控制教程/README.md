# 机器人硬件、LeRobot 与 RDK X5

本章从硬件选型出发，逐步完成 RDK X5 开发板配置、机械臂连接、遥操作与数据采集。建议先理解执行器和传感器，再进入设备实操，避免在通信、供电和标定问题之间反复排查。

## 学习路径

1. [执行器原理与选型](./05执行器原理与选型.md)：认识电机、减速器、驱动器与传动结构。
2. [传感器选型与数据采集](./06传感器选型与数据采集.md)：理解图像、深度、关节状态与触觉信号的数据链。
3. [机械臂选型](./07机械臂选型.md)：从自由度、负载、精度和开放接口评估平台。
4. [RDK X5 超新手入门](./01RDKX5超新手入门教程.md)：完成系统启动、网络和基础开发环境配置。
5. [RDK Studio 使用教程](./02RDK%20X5闪连%ef%bc%88RDK%20Studio使用教程%ef%bc%89.md)：通过桌面工具连接开发板并管理应用。
6. [RDK X5 连接 LeRobot 机械臂](./03RDK-X5连接lerobot机械臂进行遥操作.md)：完成串口识别、标定和单臂遥操作。
7. [LeRobot 双臂异构系统遥操作](./04LeRobot双臂异构系统遥操作.md)：理解多进程控制、状态同步和接口边界。

完成本章后，应能够说明供电、总线、关节状态和传感数据之间的关系；能够在 RDK X5 上识别机械臂接口；并能将一次遥操作拆分为输入、映射、执行和记录四个环节进行调试。
