## 产品介绍

### 产品概述

犀牛派 X1（Rhino Pi-X1）是一款基于 Qualcomm® QCS8550 平台的高性能嵌入式计算设备，专为边缘人工智能、工业物联网和智能计算终端设计。

Rhino Pi-X1 搭载 Qualcomm® QCS8550 SoC，采用 1+2+3 三丛集架构（1× Kryo Prime @ 3.2GHz，2× Kryo Gold @ 2.8GHz，3× Kryo Silver @ 2.0GHz），兼顾强劲性能与低功耗。内置 Adreno 740 GPU 与高效 AI 加速引擎，AI 算力高达 48 TOPS（INT8），具备卓越的多媒体处理与 AI 推理能力。

X1 支持 4K/8K 视频编解码、多路 CSI 摄像头接口、HDMI 输入输出以及 Wi-Fi 7 / Bluetooth 5.3 无线连接，提供全面的接口拓展，包括 USB 3.0、CAN、SPI、I2C、PWM、UART、LAN/WAN 等。系统支持 AidLux 融合系统（Android 13 + Ubuntu 22.04）或 Ubuntu 22.04，为 AI 应用开发与边缘计算部署提供灵活支持。

### 切换到刷机模式

1. 设备开机后，使用 USB TYPE-A 转 TYPE-C 线缆，连接电脑和设备。TYPE-A 接电脑端 USB 口，TYPE-C 口接设备端。

2. 连接好后，在 Windows 电脑端，按 `WIN + R` 输入 `cmd`，在打开的窗口执行 `adb devices`，会列出已连接设备。

<p align="center">
  <img alt="adb devices 列出设备" src="assets/rhino_x1/12-adb-devices.png" width="50%"/>
</p>

> [!TIP]
> 如果 `adb devices` 没有列出设备，则多等待一会，或者拔插一下 TYPE-C 线缆再执行该命令。

3. 切换到刷机模式，执行：

```bash
adb root
adb reboot edl
```

### YOLOv5 目标检测部署

YOLOv5 是一个单阶段结构的目标检测网络框架，本案例演示在设备端完成 YOLOv5s 的部署、加载与识别流程，支持 AidLite Python API 与 C++ API 两种部署方式（INT8 量化模型）。

**1. 下载 YOLOv5s-INT8 模型资源**

```bash
# 查询 YOLOv5s 模型
mms list yolov5s

# 下载 QCS8550 平台的 INT8 模型
mms get -m YOLOv5s -p int8 -c qcs8550 -b qnn2.31 -d /home/aidlux/yolov5s
cd /home/aidlux/yolov5s

# 解压
unzip YOLOv5s_qcs8550_w8a8.zip
```

> [!NOTE]
> 开发者也可以在 [Model Farm](https://aiot.aidlux.com/zh/models/detail/16?name=yolov5s&precisionShow=1) 网页上搜索并下载模型资源。

**2. 检查 / 安装 AidLite SDK**（要求 QNN 后端版本 ≥ 2.31，aidlite 2.3.x）

```bash
# AidLite & QNN 版本检查
dpkg -l | grep aidlite
```

如果版本低于要求，执行以下命令更新：

```bash
sudo aid-pkg update
sudo aid-pkg install aidlite-sdk
sudo aid-pkg install aidlite-qnn236
```

**3. 运行 Python API 示例**

```bash
cd /home/aidlux/yolov5s/code

# --target_model: 模型文件路径
# --imgs: 图片输入
# --invoke_nums: 循环次数
python3 python/run_test.py \
  --target_model /home/aidlux/yolov5s/models/QCS8550/W8A8/cutoff_yolov5s_qcs8550_w8a8.qnn231.ctx.bin \
  --imgs ./python/bus.jpg --invoke_nums 10
```

### VLM 视觉语言模型部署

除了目标检测，X1 还可以在完全离线的条件下运行 8B 级别的视觉语言模型（VLM）。本节以 Qwen3-VL-8B（QNN 2.48 / W4A16 量化，约 5.2 GB）为例，基于 AidGenSE 推理引擎部署，对外提供 OpenAI 兼容的 HTTP 推理服务。

**1. 更新并安装 SDK**

```bash
# 更新软件包索引
sudo aid-pkg update

# 安装 AidGenSE（生成式 AI 推理引擎服务）
sudo aid-pkg -i aidgense

# 安装 AidGen SDK 与 QNN 运行时
sudo aid-pkg -i aidgen-sdk
sudo aid-pkg -i aidgen-qnn248
```

> [!TIP]
> `aid-pkg -i` 一次只能安装一个包；安装过程会交互式询问 `[y/n]`，按提示确认即可。

**2. 查询并下载模型**

```bash
# 查看当前支持的模型（自动按板卡 SoC 过滤）
aidllm remote-list api

# 下载模型（约 5.2 GB）
aidllm pull api qwen3-vl-8b-instruct-qnn2.48-w4a16-qcs8550
```

**3. 启动推理服务**

```bash
aidllm start api \
  -m qwen3-vl-8b-instruct-qnn2.48-w4a16-qcs8550 \
  -d dsp \
  --qnn_ver 248
```

> [!IMPORTANT]
> **模型名里的 `qnn2.xx` 就是 `--qnn_ver` 该填的值**（236 / 240 / 248）。`aidllm start api` 的默认值是 240，若与模型不匹配，服务会一直卡在 `Api server starting...`。

看到 `Api server start successfully.` 后，服务即启动成功。验证服务状态（默认端口 8888）：

```bash
curl -s http://127.0.0.1:8888/v1/models
```

（可选）如需 Web 界面快速体验图片对话：

```bash
sudo aidllm install ui
aidllm start ui    # 浏览器访问 http://<板卡IP>:51104
```

## 常见问题

**Q：刷机时找不到 9008 端口？**

断电重启设备后，重新执行「[切换到刷机模式](#切换到刷机模式)」步骤（`adb root; adb reboot edl`），等待端口出现后再继续操作。

**Q：`adb devices` 没有列出设备？**

多等待一会，或拔插 TYPE-C 线缆后再次执行命令；同时确认 USB 驱动已经正确安装。

**Q：刷机失败怎么办？**

请联系阿加犀售后人员协助处理。
