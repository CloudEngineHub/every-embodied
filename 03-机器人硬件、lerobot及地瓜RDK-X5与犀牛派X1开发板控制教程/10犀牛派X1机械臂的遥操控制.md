## 环境搭建

### 连接机械臂

1. 连接机械臂，先给机械臂上电：

<p align="center"><img alt="机械臂上电" src="assets/rhino_x1/59-arm-power-on.jpg" width="50%"/></p>

2. 插入 USB 控制线，**先插左臂，后插右臂**（否则无法进行机械臂的配置）：

<p align="center"><img alt="插入左臂 USB 控制线" src="assets/rhino_x1/60-plug-left-arm-usb.jpg" width="50%"/></p>

<p align="center"><img alt="插入右臂 USB 控制线" src="assets/rhino_x1/61-plug-right-arm-usb.jpg" width="50%"/></p>

> [!IMPORTANT]
> USB 控制线必须**先插入左臂、再插入右臂**，顺序错误将无法正常进行机械臂的配置。

### 更改设备权限

查看系统识别到的 CH343 串口设备：

```bash
sudo dmesg | grep ttyCH343
```

<p align="center"><img alt="dmesg 查看 CH343 串口" src="assets/rhino_x1/62-dmesg-ttych343.png" width="50%"/></p>

```bash
ls /dev/ttyCH343USB*
```

正常应输出：

```text
/dev/ttyCH343USB0  /dev/ttyCH343USB1
```

<p align="center"><img alt="查看串口设备" src="assets/rhino_x1/63-ls-ttych343-devices.png" width="50%"/></p>

为两个串口设备赋予读写权限：

```bash
sudo chmod 666 /dev/ttyCH343USB0
sudo chmod 666 /dev/ttyCH343USB1
```

> [!NOTE]
> `ttyCH343USB0` / `ttyCH343USB1` 与插入顺序对应（先插左臂、后插右臂）；重新拔插或重启设备后需要重新执行上述授权命令。

> 官方参考：[USB 转串口设备 | APLUX Doc Center](https://rhinopi.docs.aidlux.com/rhino-x1-ubuntu/robot-dev/peripheral/serial-port-device)

## 运行代码操控机械臂

### 下载代码

XLeRobot-X1 代码仓库地址：[APLUX-Official/XLerobot-X1（Code_Resources/XLeRobot-X1）](https://github.com/APLUX-Official/XLerobot-X1/tree/main/Code_Resources/XLeRobot-X1)

### 复制手柄控制库

将 `/home/aidlux/joycon-robotics` 复制到 `/home/aidlux/lerobot/examples`：

```bash
cp -r /home/aidlux/joycon-robotics /home/aidlux/lerobot/examples/
```

> [!NOTE]
> `joycon-robotics` 为 Joy-Con 手柄控制库，安装方法见《[犀牛派 X1 板卡与手柄使用教程](09犀牛派X1板卡与手柄的使用.md)》。

### 测试手柄

在 `/home/aidlux/lerobot/examples/` 下创建 `1.py` 文件，内容如下：

```python
from joyconrobotics import JoyconRobotics
import time

joyconrobotics_right = JoyconRobotics("right")

for i in range(1000):
    pose, gripper, control_button = joyconrobotics_right.get_control()
    print(f'{pose=}, {gripper=}, {control_button=}')
    time.sleep(0.01)

joyconrobotics_right.disconnnect()
```

## 遥控说明

### 底盘控制（麦克纳姆轮驱动）

| 按键 | 功能 |
| --- | --- |
| X 按钮 | 前进 |
| B 按钮 | 后退 |
| Y 按钮 | 向左旋转 |
| A 按钮 | 向右旋转 |

### 右臂控制

| 操作 | 功能 |
| --- | --- |
| 垂直摇杆 | 控制 X 轴和 Z 轴移动（前后） |
| 水平摇杆 | 控制 Y 轴移动（左右） |
| R 按钮 | Z 轴上升 |
| 右摇杆按钮 | Z 轴下降 |
| ZR 按钮 | 夹爪控制：按住切换开合方向，继续按住线性开合 |

### 左臂控制

| 操作 | 功能 |
| --- | --- |
| 垂直摇杆 | 控制 X 轴和 Z 轴移动（前后） |
| 水平摇杆 | 控制 Y 轴移动（左右） |
| L 按钮 | Z 轴上升 |
| 左摇杆按钮 | Z 轴下降 |
| ZL 按钮 | 夹爪控制：按住切换开合方向，继续按住线性开合 |

### 头部控制（左 Joy-Con D-pad）

| 操作 | 功能 |
| --- | --- |
| 上 / 下 | 控制头部电机 2 +/- |
| 左 / 右 | 控制头部电机 1 +/- |

### 重置功能

按下 Joy-Con 上的重置按钮（右 Joy-Con 的 Home 按钮或左 Joy-Con 的 O 按钮），可以将机器人重置到零位位置。

## 问题解决

### 问题 1：提示串口连接失败

报错提示没有这个接口：

```text
Could not connect on port '/dev/ttyCH343USB0'. Make sure you are using the correct port.
Try running `lerobot-find-port`
```

<p align="center"><img alt="串口连接报错" src="assets/rhino_x1/75-serial-port-error.png" width="50%"/></p>

**解决方法**：确定机械臂已连接板卡并且插入顺序正确（先左臂、后右臂）；若没有请重新拔插，然后重新给串口授权：

```bash
sudo chmod 666 /dev/ttyCH343USB0
sudo chmod 666 /dev/ttyCH343USB1
```

<p align="center"><img alt="重新授权串口" src="assets/rhino_x1/76-serial-port-fixed.png" width="50%"/></p>

### 问题 2：标定后机械臂不按预设位置运动

如果标定后执行 `7_xlerobot_3wheels_teleop_joycon.py`，机械臂没有按照预设位置运动，请重新标定，标定过程中缓慢移动机械臂关节。
