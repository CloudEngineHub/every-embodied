## 系统使用

犀牛派 X1 默认预装 Ubuntu 22.04 系统。本章节介绍常用的系统使用功能：ADB 调试、IP 地址确认、Web / SSH 登录与文件传输。

> 官方参考文档：[系统使用 | APLUX Doc Center](https://rhinopi.docs.aidlux.com/rhino-x1-ubuntu/getting-started/system-use/)

### ADB 基本使用

ADB（Android Debug Bridge）是一个命令行工具，用于在计算机与设备之间进行通信。它支持应用安装、调试、文件传输、日志查看以及通过 USB 或网络进行设备控制。

> 官方参考：[ADB 基本使用 | APLUX Doc Center](https://rhinopi.docs.aidlux.com/rhino-x1-ubuntu/getting-started/system-use/adb_use)

#### ADB 基本命令

```bash
# 查看当前连接设备
adb devices

# 如果发现多个设备
adb -s 设备号 其他指令

# 安装 apk 文件
adb install xxx.apk

# 传递文件：
# 往设备 SDCard 传递文件
adb push PC端文件路径 /sdcard

# 从设备下载文件到 PC
adb pull 设备上文件路径 本地保存路径

# 进入 shell 环境
adb shell

# 重启设备
adb reboot
```

### IP 地址确认

#### 通过 ADB 获取 IP 地址

ADB 的安装及使用请参考上文「[ADB 基本使用](#adb-基本使用)」。

若已插入网线，执行以下命令获取 IP 地址：

```bash
# 进入设备
adb shell

# 获取 IP 地址
ifconfig eth0
```

可以看到如下输出：

> 官方参考：[IP 地址获取 | APLUX Doc Center](https://rhinopi.docs.aidlux.com/rhino-x1-ubuntu/getting-started/system-use/ip_get)

## 连接蓝牙手柄

本章节以 Joy-Con 手柄为例，介绍蓝牙手柄的驱动配置与连接方法。
> 官方参考：[LeRobot-JoyCon](https://rhinopi.docs.aidlux.com/rhino-x1-ubuntu/getting-started/system-use/file_upload](https://github.com/box2ai-robotics/lerobot-joycon))

### 配置蓝牙手柄驱动

在设备终端中（可通过 [SSH 登录](#ssh-登录) 或外接显示器进入），克隆并安装驱动库：

```bash
git clone https://github.com/box2ai-robotics/joycon-robotics.git
```

<p align="center">
  <img alt="克隆 joycon-robotics 仓库" src="assets/rhino_x1/37-git-clone.png" width="50%"/>
</p>

```bash
cd joycon-robotics
pip install -e .
```

<p align="center">
  <img alt="安装 joycon-robotics" src="assets/rhino_x1/38-pip-install-joycon.png" width="50%"/>
</p>

安装编译依赖（sudo 密码：`aidlux`）：

```bash
sudo apt-get update
sudo apt-get install -y libevdev-dev libudev-dev cmake
```

<p align="center">
  <img alt="安装编译依赖" src="assets/rhino_x1/39-install-deps.png" width="50%"/>
</p>

> [!IMPORTANT]
> 在执行 `make install` 之前，需要先完成以下两个步骤。

1. 打开 `Makefile`，将倒数第二行中的 `install_nintendo` 删除后保存修改。

<p align="center">
  <img alt="修改 Makefile" src="assets/rhino_x1/40-makefile-edit.png" width="50%"/>
</p>

2. 创建临时安装目录：

```bash
mkdir /tmp/joycon-install-temp
```

<p align="center">
  <img alt="创建临时目录" src="assets/rhino_x1/41-mkdir-tmp.png" width="50%"/>
</p>

完成以上步骤后执行安装：

```bash
make install
```

<p align="center">
  <img alt="执行 make install" src="assets/rhino_x1/42-make-install.png" width="50%"/>
</p>

### 命令行连接蓝牙

查看是否有蓝牙模块：

```bash
hciconfig
```

<p align="center">
  <img alt="hciconfig 查看蓝牙模块" src="assets/rhino_x1/43-hciconfig.png" width="50%"/>
</p>

进入蓝牙控制台：

```bash
bluetoothctl
```

<p align="center">
  <img alt="进入蓝牙控制台" src="assets/rhino_x1/44-bluetoothctl.png" width="50%"/>
</p>

打开蓝牙：

```bash
power on
```

<p align="center">
  <img alt="打开蓝牙" src="assets/rhino_x1/45-bt-power-on.png" width="50%"/>
</p>

依次注册代理并开始扫描：

```bash
agent on
default-agent
scan on
```

然后：

1. 进入配对模式：长按 Joy-Con 侧边圆形按钮 3 秒。
2. 在系统蓝牙设置中连接 Joycon (L) 或 Joycon (R)。

<p align="center">
  <img alt="Joy-Con 进入配对模式" src="assets/rhino_x1/46-bt-pairing-1.png" width="50%"/>
</p>

<p align="center">
  <img alt="连接 Joy-Con" src="assets/rhino_x1/47-bt-pairing-2.png" width="50%"/>
</p>

配对并连接：

```bash
pair 12:34:56:78:9A:BC
connect 12:34:56:78:9A:BC
```

```bash
pair 9C:54:00:E0:6C:B2
connect 9C:54:00:E0:6C:B2
```

停止扫描：

```bash
scan off
```

### 显示器连接蓝牙

如果设备已连接显示器，也可以在桌面环境中连接蓝牙手柄：

1. 将 HDMI 接口插入板卡的 HDMI-OUT 口。

<p align="center">
  <img alt="连接 HDMI" src="assets/rhino_x1/48-hdmi-connect.png" width="50%"/>
</p>

2. 插入 USB 鼠标和键盘。

<p align="center">
  <img alt="连接鼠标键盘" src="assets/rhino_x1/49-usb-mouse-keyboard.png" width="50%"/>
</p>

3. 输入密码 `aidlux` 进入系统。

4. 点击右上角选择蓝牙 Bluetooth。

<p align="center">
  <img alt="选择蓝牙" src="assets/rhino_x1/50-bt-settings.png" width="50%"/>
</p>

5. 进入配对模式：长按 Joy-Con 侧边圆形按钮 3 秒。

6. 在系统蓝牙设置中连接 Joycon (L) 或 Joycon (R)。

<p align="center">
  <img alt="连接 Joy-Con" src="assets/rhino_x1/51-bt-connect.png" width="50%"/>
</p>

### 正确连接状态

1. 绑定连接成功时 Joy-Con 会震动。
2. 单控制器模式：同时长按 R + ZR（上下两个肩键）3 秒。
3. 双控制器模式：双 Joy-Con 震动后，同时按下：左控制器的 L（顶部肩键）+ 右控制器的 R（顶部肩键）。

### 重新连接

<p align="center">
  <img alt="重新连接" src="assets/rhino_x1/52-bt-reconnect.png" width="50%"/>
</p>

- 已配对设备按 L 或 R 键自动重连。
- 等待震动提示后重复上述步骤 2。

```text

  File "/home/aidlux/Xlebot/lerobot/examples/1.py", line 1, in <module>
    from joyconrobotics import JoyconRobotics

    from .joyconrobotics import JoyconRobotics
  File "/home/aidlux/Xlebot/lerobot/examples/joyconrobotics/joyconrobotics.py", line 5, in <module>
```

执行以下命令安装 PyGLM 即可：

```bash
python -m pip install PyGLM
```

  <img alt="安装 PyGLM" src="assets/rhino_x1/58-pip-install-pyglm.png" width="50%"/>
</p>
