# 公众号文章素材

本目录保存从教材和开源项目整理出的公众号长文与发布素材，属于内容发布归档，不纳入核心教材的连续学习路线。

## 文章目录

- [EBench：从运行验证到能力诊断](./01-EBench.md)

文章面向公开传播，侧重项目背景、能力概览和实验入口；具体安装、训练与评估步骤应链接到对应教材章节或官方文档。

## 内容定位

这里的文章用于把教材中的技术主题整理成适合社区阅读的长文。文章可以介绍研究背景、方法结构、代表性结果和最小体验入口，但不重复粘贴完整环境安装日志。涉及模型成绩时，应注明任务集、评估划分和指标；涉及本地复现时，应链接到对应教材章节。

## 发布前检查

1. 标题准确描述项目或方法，不使用与正文无关的宣传语；
2. 图片、视频和数据表标明来源，外部素材具有可公开使用的出处；
3. 项目地址、论文、数据集和在线演示链接可以正常访问；
4. 安装命令、模型权重和大文件下载统一链接到教材或官方页面；
5. 删除报名二维码、内部沟通记录、临时路径和过期时间信息。

完成检查后，文章既可以独立阅读，也能把读者带回教材中的可复现实验。
