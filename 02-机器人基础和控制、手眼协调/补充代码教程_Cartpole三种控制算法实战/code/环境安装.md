# 倒立摆控制实验环境与运行入口

本页用于准备倒立摆实验依赖，并分别运行 PID、LQR 和 MPC 三种控制器。所有命令都应在 `补充代码教程_Cartpole三种控制算法实战/code` 目录执行。

## 创建环境

```shell
mamba create -n cartpole-control python=3.8
mamba activate cartpole-control
pip install setuptools==65.5.0 pip==21 wheel==0.38.0
pip install gym==0.21.0 matplotlib==3.7.5 pyglet==1.4.0 scipy==1.10.1 casadi==3.7.2
```

安装完成后，运行 `python -c "import gym, scipy, casadi; print('environment ready')"`。终端打印 `environment ready` 表示核心依赖可导入。

## 运行 PID 控制器

```shell
python cartpole-PID.py
```

## 运行 MPC 控制器

```shell
python cartpole_MPC.py
```

## 运行 LQR 控制器

```shell
python cartpole-LQR.py
```

三个脚本分别输出控制过程动画和状态曲线。若图形窗口无法打开，先检查服务器是否提供显示环境，再改用脚本中的图像或视频保存选项。
