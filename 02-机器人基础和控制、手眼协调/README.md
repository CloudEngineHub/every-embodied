基础公式章节只依赖 Python、NumPy 和 SymPy。倒立摆实验的完整依赖与运行命令见[实验环境](补充代码教程_Cartpole三种控制算法实战/code/环境安装.md)。

## 完成标准

- 能根据齐次变换矩阵完成点和坐标系之间的变换。
- 能由 DH 参数计算串联机械臂末端位姿。
- 能解释动力学方程中惯性、速度耦合与重力项的作用。
- 能用雅可比矩阵完成速度映射，并判断位置任务中的奇异位形。
- 能比较 PID、LQR 与 MPC 控制器的输入、模型依赖和调参方式。
