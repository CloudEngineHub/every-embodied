# 具身世界模型

本章介绍机器人如何通过生成模型预测未来观测、动作结果和任务进展。内容从扩散模型基础开始，逐步进入动作条件视频预测、多智能体世界建模、数据合成和策略改进。

## 前置知识

- 概率分布、条件概率和基本线性代数；
- PyTorch 训练循环与卷积网络；
- 机器人观测、动作和轨迹的基本表示。
