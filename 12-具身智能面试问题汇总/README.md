# 具身智能面试复习与知识自测

本章将机器人学、强化学习、生成模型和具身系统工程中的高频问题组织为“问题—推导—实现—验证”四个层次。建议先完成对应教材章节，再使用题库检查知识是否形成闭环。

## 使用方法

1. 第一次作答时不查资料，用两分钟说明问题定义、输入输出和关键假设。
2. 第二次作答时补充公式、算法步骤和一个可运行示例。
3. 第三次作答时说明评价指标、常见失败模式和适用边界。
4. 将不能独立回答的问题记录到[自测与复盘模板](./08面试自测与复盘模板.md)，返回对应章节补齐知识。

## 完成标准

- 能用统一符号说明观测、状态、动作、奖励和终止条件。
- 能从任务需求选择控制、模仿学习或强化学习方法。
- 能区分训练损失、开环误差和闭环任务成功率。
- 能说明仿真到真实部署中的动力学、视觉和控制频率差异。
- 能根据日志、指标和视频定位失败阶段。
