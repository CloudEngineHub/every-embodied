# 具身智能面试自测与复盘模板

每次练习选择一个问题，按下表记录。目标不是背诵固定答案，而是建立从概念到实验验证的完整表达。

| 项目 | 记录内容 |
| --- | --- |
| 问题 | 用一句话写清需要解释或比较的对象 |
| 核心定义 | 给出符号、输入、输出和假设 |
| 方法步骤 | 按数据流或控制流说明算法 |
| 关键公式 | 写出目标函数、状态更新或评价指标 |
| 工程实现 | 给出模块边界、张量形状、频率或接口 |
| 验证方法 | 说明数据集、任务、回合数和成功条件 |
| 常见错误 | 记录容易混淆的概念和失败模式 |
| 补学章节 | 链接到教材中的对应内容 |

## 三档自测标准

- **基础**：能够准确说明定义与输入输出。
- **进阶**：能够推导主要公式并解释实现步骤。
- **系统**：能够设计实验、解释结果并定位失败。

完成一次复盘后，用不超过三分钟重新口述答案；若仍需要依赖原文，应回到“核心定义”和“方法步骤”两项继续整理。
