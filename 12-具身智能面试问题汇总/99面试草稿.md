# 具身智能面试准备与复盘模板

这份模板用于把项目经历整理成可以核查的技术回答，也用于面试结束后记录问题、证据和改进项。建议复制一份到个人笔记中填写，不要直接在公共教材中写入姓名、联系方式、公司内部信息或未公开数据。

## 1. 面试前：项目说明卡

每个重点项目只填写一张说明卡，控制在一页以内。

| 项目要素 | 填写内容 |
| --- | --- |
| 任务目标 | 机器人要在什么环境中完成什么任务 |
| 观测输入 | 图像、深度、点云、关节状态、语言指令等 |
| 动作输出 | 关节位置、末端位姿、速度、力矩或离散动作 |
| 数据来源 | 数据规模、采集方式、训练集与评估集划分 |
| 模型与算法 | 策略结构、损失函数、规划器或控制器 |
| 训练配置 | 硬件、训练步数、批大小、学习率和耗时 |
| 评估协议 | 任务数量、每任务回合数、成功条件和固定种子 |
| 最终结果 | 成功率、时延、吞吐、显存和典型失败阶段 |
| 个人工作 | 独立完成的模块、修复的问题和提交记录 |

项目介绍可以按“任务—约束—方法—结果—复盘”组织：

1. **任务：** 一句话说明机器人要做什么。
2. **约束：** 说明硬件、数据、时间或部署环境的限制。
3. **方法：** 只讲与结果直接相关的设计选择。
4. **结果：** 给出固定评估协议下的数字和可观察现象。
5. **复盘：** 说明主要失败模式以及下一步最有价值的改进。

## 3. 实验题检查清单

回答训练、部署或评估问题时，优先说明以下信息：

- 张量形状、坐标系、动作单位和控制频率；
- 数据集的回合边界、时间戳、归一化统计和异常轨迹处理；
- 训练与推理是否使用相同的观测和动作定义；
- 成功判定是否检查接触、抬升、运输、放置和释放等物理阶段；
- 随机种子、任务数量、每任务回合数和结果聚合方式；
- 模型时延、控制周期、显存占用和故障恢复策略。

## 4. 面试后复盘

面试结束后尽快完成三件事：

1. 将新问题归入机器人学、感知、规划、控制、学习或工程部署类别。
2. 为关键结论补上教材章节、论文、源码或实验记录，不凭记忆保留模糊说法。
3. 选择一个最薄弱的问题，写出最小验证代码或手算过程，并记录预期输出。

复盘的完成标准不是“看懂答案”，而是能够在不查看原文的情况下，说明输入、处理过程、输出、假设和验证方法。
