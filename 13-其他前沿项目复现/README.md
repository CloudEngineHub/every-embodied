# 前沿项目复现

本章选择具身导航、多模态感知、视觉语言动作模型和高保真仿真项目，说明如何把论文或开源仓库转化为可运行、可检查的复现实验。

## 复现流程

1. 固定上游仓库版本并阅读许可证与硬件要求。
2. 列出环境、模型、数据和场景资产，避免把下载步骤藏在运行脚本中。
3. 先运行最小环境检查，再运行推理或训练流程。
4. 明确结果属于官方预训练模型、本地微调模型还是从头训练模型。
5. 保存任务配置、指标和可视化结果，并按官方协议解释结果。

## 交付检查

- 环境版本和工作目录明确。
- 下载命令与大文件目录明确。
- 最小运行命令能够产生可检查输出。
- 训练与评估使用的模型路径一致。
- 指标的任务数、回合数和成功条件明确。
