# 具身智能数据与评估基准

本专题回答三个问题：机器人数据如何组织，策略如何在固定协议下比较，实验结果如何保留为可复查记录。建议先学习 LIBERO 和 SimplerEnv，再根据项目需要进入数据采集或生成式操作评估。

## 评估记录建议

一次可比较的机器人策略评估至少应固定：任务集合、初始状态或随机种子、每个任务的回合数、最大步数、成功判定、模型权重、动作后处理和软件版本。除总成功率外，长时程任务还应记录接近、接触、抓取、运输和放置等阶段结果。

## 完成标准

- 能辨认数据中的观测、状态、动作、任务指令和回合边界。
- 能说明离线动作误差与在线闭环成功率的区别。
- 能按照固定任务分母运行评估，并保存逐回合结果和代表性视频。
