## 5.2 脱敏处理

- 删除了公开 Task E 校验文件中的本机绝对路径，只保留校验值和公开文件名；校验值未改变。
- 原始 Workspace Memory 含有机器路径和环境细节，没有直接公开；公开版本已改成中文、路径无关的赛后复盘。
- Task B 视频和截图保留了“环境视角仅用于调试”的标记，没有把环境视角写入正式 observation contract。
- 发布前检查了 token、密码、私钥、私有 IP、机器绝对路径和带认证 URL。
- 外部选手方案只保留公开链接、固定 commit、许可证和迁移边界，不把自报成绩写成官方成绩。

## 5.3 已删除的本地副本

以下内容已存在公开归档，或明确属于不可复现的中间产物，因此不再作为本地保留源：

- 已上传 HF 的官方源码压缩包、官方指南、Task B 视频/截图和历史 Task E XSA 资料；删除对应本地下载副本。
- 已上传并脱敏后的公开资料对应的原始 Workspace Memory；删除本地含机器路径版本，仅保留公开中文版本。
- 约 42 GB 的 Task E OpenPI 失败/中间 checkpoint；公开 Task E 复现说明明确排除这些失败训练状态。
- 约 6.1 GB 的 Task E LeRobot 转换中间数据；公开复现使用 HF 上的过滤后 HDF5 分片，而不是这些转换副本。
- HF 上传过程产生的临时 staging 文件和本地媒体输出副本。

没有删除 Every Embodied 仓库中的公开教程，也没有改动与 ATEC 无关的工作区修改。

## 5.4 复现边界

删除本地副本后，公开资料可以复现：

1. 教程中的观测审计、发布扫描、文件清单和外部方案对照。
2. 官方源码快照、官方指南和历史实验资料的定位与哈希校验。
3. Task E 过滤数据的下载、分片合并、哈希校验和 ACT 复现入口。
4. Task B 调试媒体的证据阅读和“环境视角不属于正式观测”的判断。

公开资料不能保证只靠 `git clone` 或 HF 下载就启动完整 Task B 评分。完整仿真仍需要匹配的 Isaac Sim/Isaac Lab、GPU 驱动、Python 依赖、官方 runner 和评测器；当前公开归档也没有声称存在一个已经核验的 Task B 完整得分 checkpoint。
