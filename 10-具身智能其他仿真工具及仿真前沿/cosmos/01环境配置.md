# Cosmos Predict 1 环境配置

本页完成 Cosmos Predict 1 源码获取、Conda 环境创建和 Transformer Engine 安装。建议在项目根目录执行，并把模型与数据下载到独立的大容量目录。

## 创建环境

```bash
git clone git@github.com:nvidia-cosmos/cosmos-predict1.git
cd cosmos-predict1



# Create the cosmos-predict1 conda environment.
conda env create --file cosmos-predict1.yaml
# Activate the cosmos-predict1 conda environment.
conda activate cosmos-predict1
# Install the dependencies.
pip install -r requirements.txt
# Patch Transformer engine linking issues in conda environments.
ln -sf $CONDA_PREFIX/lib/python3.10/site-packages/nvidia/*/include/* $CONDA_PREFIX/include/
ln -sf $CONDA_PREFIX/lib/python3.10/site-packages/nvidia/*/include/* $CONDA_PREFIX/include/python3.10
# Install Transformer engine.
pip install transformer-engine[pytorch]==1.12.0
```

## 验证

```bash
python -c "import torch; import transformer_engine; print(torch.cuda.is_available())"
```

命令应完成导入并输出加速设备可用状态。若导入失败，先确认当前终端已经激活 `cosmos-predict1` 环境，再检查 PyTorch、CUDA 和 Transformer Engine 的版本是否与项目依赖文件一致。
