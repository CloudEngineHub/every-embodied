# RoboGen 环境配置与最小验证

本页完成 RoboGen 源码安装、PyBullet 导入验证和 OMPL 绑定配置。大模型服务所需的访问凭据应通过环境变量注入，不要写入源码。

## 安装 RoboGen

```bash
   # 克隆RoboGen仓库
   git clone https://github.com/Genesis-Embodied-AI/RoboGen.git

   # 设置环境
   conda env create -f environment.yaml
   conda activate robogen

   # 在gpt_4/query.py顶部设置OpenAI API密钥

   # 生成与微波炉相关的任务
   python run.py --category Microwave
   pip install openai pybullet 

   # 或者基于特定描述生成任务
   python gpt_4/prompts/prompt_from_description.py --task_description "A mobile franka arm heats the corn with the bowl and the microwave" --object "Microwave"
```

## 验证 Python 环境

安装完成后，先确认终端使用的 Python 确实来自 `robogen` 环境，再检查 PyBullet：

```bash
which python
python -c "import pybullet; print('PyBullet import passed')"
```

如果出现 `ModuleNotFoundError`，请在当前环境中重新安装 `pybullet`。如果出现 NumPy 1.x 与 2.x 的二进制接口不兼容，请优先按项目依赖文件固定 NumPy 版本，然后重装与该版本匹配的 PyBullet。

## 安装 OMPL

要从源代码安装 OMPL，请运行

    ./install_ompl_1.5.2.sh --python

该脚本默认面向系统 Python，并可能执行系统软件包升级。在共享服务器上运行前，应先审核脚本并确认不会破坏已有环境。安装完成后，可将 OMPL 的 Python 绑定目录写入当前环境的 `site-packages`：

```bash
export ROBOGEN_ROOT=/path/to/RoboGen
export SITE_PACKAGES="$(python -c 'import site; print(site.getsitepackages()[0])')"
printf '%s\n' "$ROBOGEN_ROOT/ompl-1.5.2/py-bindings" > "$SITE_PACKAGES/ompl.pth"
python -c "import ompl; print('OMPL import passed')"
```

请将 `ROBOGEN_ROOT` 替换为实际仓库路径。
