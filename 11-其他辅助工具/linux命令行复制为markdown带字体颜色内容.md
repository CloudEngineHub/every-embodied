# 将彩色终端输出复制到 Markdown 文档

支持富文本复制的终端可以把 ANSI 颜色转换为 HTML，再粘贴到支持 HTML 的 Markdown 编辑器中。这适合保留短日志的颜色层次，不适合粘贴包含凭据或大量重复输出的完整日志。

## 生成测试输出

```bash
printf '\033[32mPASS\033[0m  environment ready\n'
ls --color=always
```

在终端中选中需要的行，右键选择 **Copy as HTML**，再粘贴到 Markdown 编辑器。若编辑器过滤内联样式，可以先粘贴到浏览器富文本编辑区，再复制为 HTML 片段。

![终端富文本复制菜单](./assets/image-20260117161900470.png)

## 验证与排错

预览 Markdown 页面，文字颜色和换行应与终端基本一致。若只得到纯文本，确认终端支持富文本复制，并检查所选菜单是否为 **Copy as HTML** 而不是普通复制；若背景色导致文字不可读，删除 HTML 中的背景样式，仅保留前景色。
