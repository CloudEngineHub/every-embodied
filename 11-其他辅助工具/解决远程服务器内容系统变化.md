# 处理 SSH 远程主机密钥变化

服务器重装、实例重建或端口映射变化后，SSH 可能提示远程主机标识已改变。这项检查用于阻止连接被冒充，因此应先向服务器管理员确认新主机密钥，再更新本地记录。

## 确认目标服务器

先核对服务器地址、端口和重建时间。确认变化符合预期后，删除该地址的旧记录：

```bash
ssh-keygen -R "[server.example.com]:2222"
```

重新连接并人工核对终端显示的主机密钥：

```bash
ssh user@server.example.com -p 2222
```

## 验证与排错

接受新密钥后再次连接，不应再出现主机标识变化提示。若提示仍存在，检查实际连接的主机名、端口和 `%USERPROFILE%/.ssh/known_hosts` 中对应条目；若无法从可信渠道确认新密钥，应停止连接并联系管理员。
