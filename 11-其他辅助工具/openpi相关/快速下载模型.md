
# 使用 s5cmd 下载 OpenPI 模型

公开的 OpenPI 对象存储可以通过 `s5cmd` 匿名并发下载。先进入希望保存模型的目录，再执行以下命令。

```bash
wget 'https://github.com/peak/s5cmd/releases/download/v2.3.0/s5cmd_2.3.0_linux_amd64.deb'
sudo apt install ./s5cmd_2.3.0_linux_amd64.deb

export S3_ENDPOINT_URL=https://storage.googleapis.com

s5cmd --no-sign-request cp --concurrency 50 "s3://openpi-assets/checkpoints/pi0_fast_droid_jointpos/*" ./pi0_fast_droid_jointpos/
```

下载结束后运行 `find ./pi0_fast_droid_jointpos -type f | head`，应能看到模型配置和权重分片。若出现连接超时，降低并发数并重新执行同一命令；已完成的文件会保留在目标目录中。
