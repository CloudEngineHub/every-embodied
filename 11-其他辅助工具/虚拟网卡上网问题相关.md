# 将 Windows 虚拟网卡设置为专用网络

当代理软件创建的虚拟网卡被 Windows 识别为公用网络时，防火墙策略可能阻止局域网访问。可以在本地安全策略中把对应网络改为专用网络。

参考讨论：https://linux.do/t/topic/276425

## 修改网络位置

1. 按 `Win+R`，输入 `secpol.msc` 并回车。
2. 打开 **网络列表管理器策略**。
3. 双击代理软件创建的网络，例如 Mihomo。
4. 在 **网络位置** 中选择 **专用**，保存后重启代理软件。
在策略列表中，应根据“网络名称”和“描述”确认目标虚拟网卡，不要修改当前上网使用的实体网卡。修改后断开并重新连接代理，再进行验证。

## 验证与排错

在 PowerShell 中执行：

```powershell
Get-NetConnectionProfile
Test-NetConnection github.com -Port 443
```

目标虚拟网卡的 `NetworkCategory` 应为 `Private`，端口测试应成功。若系统没有 `secpol.msc`，可使用管理员 PowerShell 的 `Set-NetConnectionProfile` 设置网络类别；修改前先用 `Get-NetConnectionProfile` 确认正确的接口名称。
