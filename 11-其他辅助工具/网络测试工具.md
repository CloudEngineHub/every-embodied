# Linux 网络带宽与连接测试

网络问题应分成进程占用、端到端吞吐和外网连通性三类检查。本页分别使用 `nethogs`、`iperf3` 和 `curl` 定位问题。

## 查看进程带宽

```bash
sudo apt-get update
sudo apt-get install -y nethogs
sudo nethogs
```

界面会按进程显示实时上传和下载速度，按 `q` 退出。

![nethogs 进程带宽界面](assets/image-20251026115247175.png)

## 测试两台机器之间的吞吐

服务端执行：

```bash
iperf3 -s
```

客户端执行：

```bash
iperf3 -c <SERVER_IP> -P 4
```

## 验证与排错

```bash
curl -I --connect-timeout 10 https://github.com
ip route
```

若域名访问失败但 IP 可通，检查 DNS 配置；若 `iperf3` 无法连接，确认服务端端口和防火墙规则；若只有单个进程占满带宽，可回到 `nethogs` 查明进程后再调整并发数。
