# 具身智能概述

本专题建立后续课程共用的概念框架。完成学习后，应能说明具身智能系统的感知、决策、行动与反馈闭环，识别机器人主要硬件和软件模块，并根据任务选择合适的机器人形态。

## 学习顺序

1. [具身智能基本概念](01具身智能概述.md)：理解具身智能的定义、系统闭环、应用场景与主要挑战。
2. [机器人发展历史与背景](module1_1_机器人发展历史与背景/README.md)：从控制论、工业机器人到通用机器人，梳理关键技术演进。
3. [机器人系统组成与分类](module1_2_机器人系统组成与分类/README.md)：认识机械结构、驱动、感知、控制和软件系统。

## 完成标准

- 能画出“环境观测—状态估计—策略决策—执行器动作—环境反馈”的闭环。
- 能区分工业机械臂、移动机器人、人形机器人和特种机器人的典型任务。
- 能解释数据、仿真、控制和真实硬件在具身智能开发中的关系。

## 继续学习

掌握本专题后，进入[机器人基础和控制](../02-机器人基础和控制、手眼协调/README.md)，学习坐标变换、运动学、动力学和闭环控制。
