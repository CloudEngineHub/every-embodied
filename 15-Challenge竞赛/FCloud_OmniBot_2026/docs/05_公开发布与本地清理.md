# 公开发布与本地清理

## 发布分层

| 位置 | 内容 | 明确排除 |
| --- | --- | --- |
| GitHub `15-Challenge竞赛/FCloud_OmniBot_2026/` | 中文教程、轻量代码、配置模板、结果边界和引用 | 权重、缓存、私密日志、令牌、私有地址 |
| Hugging Face［模型与数据托管平台］`Datawhale/fcloud-omnibot-2026-reproducibility` | 源码快照、清单、脱敏实验记录、代表性视频 | 密码、私钥、未授权资产、完整环境 |
| 本机工作区 | 只保留 `WORKSPACE_MEMORY.md`［工作区记忆］ | 原始日志、缓存、环境、下载包和中间视频 |

## 下载归档

```bash
git clone https://github.com/datawhalechina/every-embodied.git

# Hugging Face 数据集归档
git clone https://huggingface.co/datasets/Datawhale/fcloud-omnibot-2026-reproducibility
```

Hugging Face［模型与数据托管平台］仓库中的 `MANIFEST.sha256`［文件校验清单］用于核对下载文件；视频和日志只作为证据，不自动等价于比赛成绩。

## 发布前检查

```bash
rg -n -i \
  'hf_[A-Za-z0-9]{20,}|sk-[A-Za-z0-9_-]{20,}|password|secret|private[_-]?key|api[_-]?key|/home/ubuntu|/data/Data' \
  15-Challenge竞赛/FCloud_OmniBot_2026
```

检查要求：令牌、密码和私钥为零；本机绝对路径替换为 `$PROJECT_ROOT`［项目根目录］、`$DATA_ROOT`［数据根目录］或示例路径；日志中移除私有地址和带认证链接；第三方代码保留上游地址、版本和许可证。

## 清理原则

只有在 GitHub 推送成功、Hugging Face 文件可下载、校验清单生成、代表性视频可播放后，才删除本机 14omnibot 原始目录。清理范围不应扩大到其他项目共用的 `/data/Data14TB/`［14TB 数据盘］参考仓库、模型缓存或环境。
