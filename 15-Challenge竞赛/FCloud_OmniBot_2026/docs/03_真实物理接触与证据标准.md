# 真实物理接触与证据标准

## 合格视频的判定

一个抓取放置回合只有同时满足下面条件，才进入训练池或公开结果：

1. 夹爪从打开状态接近物体，指尖或夹持面真实接触物体。
2. 闭爪后，物体位姿随机器人抬升而变化，而不是被脚本直接设置或绑定到手。
3. 运输阶段物体保持在夹爪约束中，没有穿透、瞬移、飞行或由轨迹脚本跟随。
4. 放置后松开夹爪，物体仍停留在目标区域内。
5. 视频、逐步日志、最终物体位姿和成功判断彼此一致。

## 必须保存的材料

```text
episode/
├── video_*.mp4              # 至少一个能看清全身、目标和容器的视角
├── keyframes.*              # 接近、接触、闭爪、抬升、运输、放置关键帧
├── steps.jsonl              # 每步动作、阶段、时间戳和观测摘要
├── summary.json             # 成功判断、终态误差和失败原因
├── config.yaml              # 场景、随机种子、控制参数
└── README.md                # 运行命令和证据边界
```

如果使用真值教师生成数据，应在 `summary.json` 中写明：`observation_source=oracle_teacher`［真值教师观测］；如果使用机器人自身相机，应记录相机名、帧时间戳和坐标系变换。

## 常见假成功

- `bootstrap_object_follow=true`［物体跟随手］：可以验证数据格式，但不是接触抓取。
- 直接修改物体位姿：可以生成漂亮终态，但不能作为物理成功。
- 只记录手臂轨迹：缺少相机、夹爪和物体结果，不能复核闭环。
- 仅有 `reward`［奖励值］：奖励可能只表示接近、阶段完成或脚本分支，不等价于物体已放好。
- 仅有短视频：无法判断中间是否瞬移或接触断开。

## 训练数据门禁

建议在进入数据集前执行四个门禁：

- 轨迹回放门禁：原始动作在同一环境中可复现；
- 物理门禁：物体高度、位姿和接触状态符合真实接触；
- 视频门禁：逐帧画面没有瞬移、穿透、黑屏或关键阶段缺失；
- 协议门禁：策略输入没有混入世界坐标、评估器结果或外部相机。
