# FCloud OmniBot 2026：赛后复盘与公开归档

本目录记录 FCloud OmniBot 2026 具身智能挑战赛的公开规则、环境拆分、规划与数据采集路线，以及赛后可复现的工程经验。比赛已经结束，本目录不声称存在冠军方案，也不把诊断视频或训练接口验证写成正式成绩。

## 先看结论

- 比赛主环境是 FCloud OmniBot 的 Isaac Sim［机器人仿真器］/Isaac Lab［机器人学习框架］场景，不能用 CAPX/B1K［家庭环境基线］或 Unitree［宇树官方环境］的结果替代。
- 任务包含人形机器人自主导航避障、桌面整理、视觉与自然语言理解三个方向。桌面整理要求真实抓取、搬运和放置，最终以物体位姿误差与视频证据为准。
- SIMPLE［合成数据与状态机框架］的 G1 全身弯腰抓取放置数据证明了“状态机 + 规划 + 真实物理接触 + 多视角记录”这条数据生成路线可行，但它是迁移参考，不是 FCloud 最终成绩。
- MuJoCo［物理仿真器］水果抓取样例完成过真实接触的抓取、抬升、搬运和放置，可作为两指夹爪与视频验收的最小教师案例；它不是比赛机器人或比赛场景。
- Unitree G1 Dex1［宇树 G1 两指夹爪版本］的 Quest 3［虚拟现实头显］采集栈曾跑到连接、同步和记录状态，但没有把完整比赛任务核验成稳定成功数据。
- CAPX/B1K 的环境加载、哈希修复、LLM［大语言模型］代理和桌边导航曾分别验证，手臂预抓取与完整任务仍未形成有效成功回合。

## 结果阅读规则

本目录把结果分成三类：

1. **物理成功证据**：视频中可以看到夹爪接触、物体随夹爪抬升、运输后放置，且结构化指标与画面一致。
2. **工程链路证据**：环境、相机、控制接口、数据格式或自评分器已经跑通，但不代表任务成功。
3. **未解决问题**：日志或视频明确显示规划失败、碰撞扫落、夹爪未形成约束或评分未通过。

读者应先看视频和 `summary.json`［结构化摘要文件］，再参考文字结论；不能仅凭物体坐标被脚本改变、`reward`［奖励值］非零或视频生成成功来认定抓取成功。
