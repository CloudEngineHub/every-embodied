# 轻量代码说明

本目录中的代码是比赛项目的公开快照，主要用于理解接口、数据记录和离线自评。它不是包含 Isaac Sim［机器人仿真器］、Isaac Lab［机器人学习框架］和官方资产的一键环境。

## 代码边界

- `omnibot_agent/`：观测、规划、动作适配、日志和本地自评相关的轻量模块。
- `configs/`：与公开接口相关的配置模板；本机路径和令牌已移除。
- 真实运行需要把 `$PROJECT_ROOT`［项目根目录］、`$DATA_ROOT`［数据根目录］和 `$MODEL_ROOT`［模型根目录］替换成自己的路径。

## 推荐顺序

1. 先运行纯 Python［编程语言］自检和 JSON［结构化数据格式］评分。
2. 再在已经安装官方仿真环境的机器上做单回合相机和动作接口测试。
3. 最后才接真实策略、训练和完整评测。

脚本中带有 `oracle`［真值教师］、`bootstrap`［启动验证］或 `smoke`［冒烟测试］的输出只能用于链路验证；若没有真实接触视频，不应作为正式成功数据。
