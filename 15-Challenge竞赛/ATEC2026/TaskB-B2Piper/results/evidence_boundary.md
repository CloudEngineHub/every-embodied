# 评估证据边界

## 可以证明什么

- 官方任务定义和观测边界可以由官方仓库核验。
- 公开参考方案确实包含 Task B 的搜索、导航、末端锁定和分类文档，可以由公开 GitHub 链接核验。
- 本地第三方环境相机适合帮助观察全局行为，但不属于策略输入。
- 近距离、触碰和接触指标可以用于故障定位。

## 不能仅凭这些证明什么

- 一张环境视角截图不能证明策略只使用了合法传感器。
- 机器人走到物体附近不能证明抓取成功。
- 夹爪闭合不能证明物体被夹持。
- 物体短暂移动不能证明已经放入垃圾桶。
- 外部仓库存在 demo 代码不能证明其最终成绩或完整闭环已被官方评测器确认。

## 完整成功的最低证据

1. 官方 runner 和评测器版本可追溯。
2. 运行日志中的 policy 输入只来自合法 observation。
3. 夹爪闭合后物体随末端提起并保持。
4. 携带物体到达垃圾桶并释放。
5. 释放后物体满足官方放置判定。
6. 保存原始视频、逐步日志、seed 和官方分数。
