# 具身智能参考项目索引

本页收录适合作为课程延伸阅读的开源项目。使用参考项目时，应先确认许可证、依赖版本和硬件要求，再将其接口接入自己的实验环境。

## Matrix

- 项目地址：<https://github.com/zsibot/matrix>
- 建议关注：项目目录组织、机器人任务接口、模型与控制模块的连接方式。
- 阅读方法：先查看项目说明和最小示例，再定位环境定义、动作空间和评估入口。运行示例前应新建独立环境，避免依赖版本影响主课程环境。

## 项目筛选清单

引入新的参考项目时，至少记录以下信息：

1. 项目解决的机器人任务及其输入、输出；
2. 支持的仿真器、机器人本体和操作系统；
3. 训练、推理与评估的独立入口；
4. 数据集、模型权重和许可证要求；
5. 最小运行示例的预期输出。

按照这份清单整理后，参考项目就能与教材中的环境搭建、策略训练和评估章节建立明确对应关系。
