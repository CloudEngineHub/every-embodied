# 参考资料与延伸阅读

本章收录具身智能相关的开源项目、课程、论文入口和学习社区。参考资料用于扩展教材内容，具体安装命令、许可证和评估协议应以对应上游项目的当前文档为准。

## 使用原则

1. 先从教材章节建立问题定义，再选择参考项目。
2. 优先阅读论文、官方文档和官方仓库。
3. 复现实验时固定代码版本，并记录模型与数据来源。
4. 比较结果时统一任务、数据、回合数和成功条件。

完整列表见[参考项目](./参考项目.md)。

## 按学习方向查找

- **机器人学与控制**：运动学、动力学、规划和控制库。
- **感知与重建**：目标检测、分割、深度、点云和三维重建。
- **机器人学习**：模仿学习、强化学习和视觉语言动作模型。
- **仿真与数据**：机器人仿真器、场景资产、数据采集和生成工具。
- **导航与移动操作**：定位、建图、规划、视觉语言导航和家庭任务。
- **系统设计**：机械结构、硬件接口、部署和评估工具。

发现失效链接或重要的新项目时，请在[参考项目](./参考项目.md)中补充项目名称、官方入口、用途和适用章节。
