# Focused Study Programs

This volume contains time-bounded study programs that combine reading, implementation, experiments, and publication.

Begin with the [Damo Academy study program](./01-damo-academy-team-learning/README.md), then select a project track according to the hardware and simulator available to your team.

Every program should end with a runnable artifact, an evaluation record, and a concise technical summary rather than a collection of meeting notes.
