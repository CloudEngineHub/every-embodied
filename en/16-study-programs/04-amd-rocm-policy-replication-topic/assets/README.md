# Asset Description

This directory contains the small teaching images used in the AMD ROCm policy replication project. The charts and keyframe sequences are generated by `../code/generate_tutorial_assets.py` to verify the success rate and rollout behavior of the tutorials; the screenshots in `aup_cloud_guide/` come from the AMD / AUP cloud platform usage guide compressed package.

When generating the chart again, first prepare your experiment output directory, and then run:

```bash
python code/generate_tutorial_assets.py --source-root "$OUTPUT_ROOT"
```

`$OUTPUT_ROOT` should include batch evaluation JSONL/TSV and representative rollout videos. If `--source-root` is not provided, the script will generate charts using built-in example metrics and placeholder images for missing videos.

| `pnp_four_view_strict_success_sequence.jpg` | Sequence of critical frames at 5 moments in the four-perspective video |
