# Robot Manipulation and VLA Policies

This chapter studies vision-language-action policies, manipulation data, policy training, closed-loop evaluation, and failure diagnosis.

Start with the [VLA overview and survey](./01-vla-overview-and-survey.md). Then use the Chinese source chapter for the newest laboratory material while the English backfill is updated.

The expected workflow is: inspect the task contract, audit the dataset, train a policy, evaluate the exact checkpoint produced by that run, and inspect both metrics and videos.
