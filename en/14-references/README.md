# References and Further Reading

This appendix collects open-source projects, courses, papers, tools, and communities related to embodied AI. Use these materials to extend a textbook topic; verify installation commands, licenses, and evaluation protocols against the current upstream documentation.

## How to Use This Appendix

1. Establish the problem definition in the textbook before selecting a reference project.
2. Prefer papers, official documentation, and official repositories.
3. Pin the code revision and record model and dataset sources during reproduction.
4. Align tasks, data, episode counts, and success conditions before comparing results.

The complete list is available in the [reference project index](./reference-project.md).

## Browse by Direction

- **Robotics and control:** kinematics, dynamics, planning, and control libraries.
- **Perception and reconstruction:** detection, segmentation, depth, point clouds, and 3D reconstruction.
- **Robot learning:** imitation learning, reinforcement learning, and vision-language-action policies.
- **Simulation and data:** robot simulators, scene assets, data collection, and generation tools.
- **Navigation and mobile manipulation:** localization, mapping, planning, vision-language navigation, and household tasks.
- **System design:** mechanical structures, hardware interfaces, deployment, and evaluation tools.
