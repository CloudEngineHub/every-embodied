# Reference Projects

This chapter collects external projects that complement the textbook. Each entry should be reviewed for its license, supported hardware, dependency versions, and maintenance status before reuse.

## Matrix

- Repository: <https://github.com/zsibot/matrix>
- Scope: reusable robotics software components and examples.
- Suggested use: compare its hardware abstraction, message flow, and deployment layout with the interfaces introduced in this textbook.

When adding another project, include a direct upstream link, a one-sentence scope statement, the relevant textbook chapter, and the exact reason it is useful. Avoid adding bare links without explaining what a learner should inspect or reproduce.
