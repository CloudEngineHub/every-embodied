# Monthly Team-Learning Archive

This archive preserves six iterations of the community learning path. It documents how the course schedule, recommended exercises, and specialization tracks evolved, but it is not a continuous chapter of the main textbook. Read the latest version first, then consult earlier versions when tracing a particular activity or curriculum decision.

- [Version 6](./06-team-learning-path-v6.md): reorganizes the curriculum around manipulation, perception, navigation, and world models.
- [Version 5](./05-team-learning-path-v5.md): expands the manipulation, navigation, application, and world-model tracks.
- [Version 4](./04-team-learning-path-v4.md): distinguishes priority reproductions from advanced follow-up work.
- [Version 3](./03-team-learning-path-v3.md): preserves the first common task and adjusts the later branches.
- [Version 2](./02-team-learning-path-v2.md): introduces the common-foundation-first, specialization-second structure.
- [Version 1](./01-team-learning-path-v1.md): records the initial beginner curriculum.

When preparing a new session, start from the latest version and update teaching roles, check-in links, and dates from the current community announcement. For technical study, follow the textbook catalog to the relevant chapter rather than treating this archive as the primary learning sequence.
