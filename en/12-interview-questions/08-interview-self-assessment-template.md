# Embodied AI Interview Self-Assessment Template

Use one copy of this table for each practice question. The goal is to connect a definition to implementation and evaluation rather than memorize a fixed answer.

| Item | Notes |
| --- | --- |
| Question | State the comparison or problem in one sentence |
| Definition | List symbols, inputs, outputs, and assumptions |
| Method | Explain the data flow or control flow |
| Equations | Record the objective, update rule, or metric |
| Implementation | State interfaces, tensor shapes, and frequencies |
| Evaluation | State tasks, episodes, and success conditions |
| Common errors | Record confusions and failure modes |
| Review chapter | Link to the relevant textbook material |

Rate each answer as foundational, implementation-ready, or system-level, then repeat it in under three minutes without reading the source text.
