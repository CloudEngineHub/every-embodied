# Public Material Instructions

GitHub only retains the material descriptions; the masked simulation preview videos and screenshots are placed in the corresponding Datawhale Hugging Face datasets `TaskB-B2Piper/videos/` and `TaskB-B2Piper/frames/`.

The recommended public video should include at least a head view, a end view, and a third-party environment view, and be synchronized using the same `episode_id` or simulation timestamp. The environment view must be labeled as a debugging view in the video description, so that readers do not mistake it for policy inputs.

The current media are only local debug/evaluation previews, not official rankings proofs. The `privileged trace` is used in the `top-down/global` perspective, and it is only used to explain the reasons for failures.
