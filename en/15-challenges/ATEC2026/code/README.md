# ATEC2026 Lightweight Code

This section contains lightweight code that can be directly placed in the tutorial repository. It does not include Isaac Sim, model weights, training cache, or complete third-party repositories.

## Files

- `taskd_reference_adapter.py`: Demonstrates the adaptation of the Logic-TARS-style 16D locomotion action to the 24D official action, as well as the Task D phase division based on score.
- `external_repo_audit/clone_references.sh`: Obtain public external reference repositories by fixed commits.
- `external_repo_audit/external_repos.yaml`: Repository, commit, license, and migration usage list.

## Boundary

These files are used to understand the interface and reproduction data organization. They are not official submission packages, and do not contain policies that ensure high scores.
