# Install Chinese Input Method For Ubuntu

```
sudo apt update
sudo apt install ibus-libpinyin
ibus restart

ibus-setup
```

Perform manipulation in the pop-up window



After entering the above command, a window named "IBus Preferences" will appear:

1. Click the **Input Method (输入法)** tab at the top.
2. Click the **Add (添加)** button on the right side.
3. In the list, select sequentially: **Chinese (中文)** -> **Intelligent Pinyin (智能拼音)** -> **Add (添加)**.
