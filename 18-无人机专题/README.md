# 无人机控制与轨迹规划

本章以四旋翼为对象，介绍从坐标变换、动力学建模到控制器和轨迹规划的完整链路。两篇教程都包含公式推导与 Python 验证，可按“先控制、后规划”的顺序学习。

## 前置知识

- 线性代数、常微分方程和基础优化；
- Python、NumPy 与 Matplotlib；
- 机器人坐标系和反馈控制基础。

## 章节目录

1. [四旋翼无人机控制教程](./无人机控制教程.md)：旋转矩阵、动力学、微分平坦性、PID、模型控制、三维跟踪、SE(3) 控制与 MPC。
2. [四旋翼无人机轨迹规划教程](./无人机规划教程.md)：多项式轨迹、Minimum Snap、走廊约束、时间分配和闭式求解。

## 学习成果

完成本章后，读者应能解释规划器与控制器的接口，推导四旋翼的基础动力学，并运行教程中的轨迹生成和跟踪验证代码。
