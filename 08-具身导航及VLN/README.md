# 具身导航与视觉语言导航

本专题从经典地图导航出发，逐步进入 Habitat 仿真、连续环境视觉语言导航和主动感知。学习重点是把观测、地图、目标、规划器、控制器和评估指标连接成完整导航闭环。

## 学习顺序

1. [导航算法基本概念](01快速入门导航算法详解及实战/具身导航算法基本介绍.md)
2. [Habitat-Sim 环境与数据集](02仿真环境基础/habitat导航环境/habitat_sim环境搭建及数据集介绍.md)
3. [Habitat-Sim 基础实践](02仿真环境基础/habitat导航环境/habitat_sim基础实践.md)
4. [Habitat-Lab 基础](02仿真环境基础/habitat导航环境/habitat_lab基础.md)
5. [Habitat-Lab 配置与环境搭建](02仿真环境基础/habitat导航环境/habitat_lab环境搭建及配置.md)
6. [Habitat-Lab 自动导航实践](02仿真环境基础/habitat导航环境/habitat_lab基础实践.md)
7. [连续环境视觉语言导航方法](03前沿VLN复现/01VLNCE/01连续环境下视觉语言导航（VLN-CE）方法概述.md)

9. [NBS 主动感知导读](03前沿VLN复现/03-主动感知NBS导读/README.md)

## 完成标准

- 能区分定位、建图、全局规划、局部规划和运动控制。
- 能在 Habitat 中加载场景、配置传感器、生成导航轨迹并读取指标。
- 能解释视觉语言导航与点目标导航在目标表达和策略输入上的差异。
- 能用成功率、路径长度加权成功率和到目标距离比较导航策略。
